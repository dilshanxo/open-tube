# PySide6 UI Skill

## Principles
- **PySide6 Standards**: Use proper signals/slots, do not block the main thread.
- **Design System**: Grayscale design, professional minimal aesthetic.
- **Components**: Reusable, isolated components for cards, inputs, buttons.
- **State Handling**: Explicit loading, error, and empty states.
- **Accessibility**: Keyboard support, tab order, focus states.
- **Responsiveness**: Use layouts (QVBoxLayout, QHBoxLayout, QGridLayout, QSplitter) correctly.
